Issue and return books

Use the Books page to issue or return a book using its action button.

How it works

  1. Open the Books page.
  2. Find a book marked Available and click Issue.
  3. When the book is returned, click Return to make it available again.

This student demo stores data in your browser using local storage. It does not yet provide multi-user accounts or a database.
