# Online Train Reservation System

A responsive train reservation demonstration built with HTML, CSS and JavaScript.

## Features
- Search sample trains by origin and destination
- View train routes, timings, classes, sample seat availability and fares
- Select seats and enter passenger details
- Generate a demo PNR for each reservation
- View reservation history and cancel tickets
- Responsive design for desktop and mobile
- Browser local storage for demo records

## Run locally
Open `index.html` in a browser, or run `npm start` and visit `http://localhost:3003`.

## Academic project note
This is a frontend demonstration using sample train data and browser local storage. It does not connect to live railway schedules, process actual payments, issue official railway tickets, or provide real PNR status.
