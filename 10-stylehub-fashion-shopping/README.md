# Experiment 10 – StyleHub Online Fashion Shopping

## Aim
To design and implement a responsive web application for **StyleHub Online Fashion Shopping** using HTML, CSS and JavaScript.

## Main features
- Browse and search available fashion.
- Sort options by price where applicable.
- Submit a demo add to cart request with user details.
- View submitted records in the My activity page.
- Cancel or withdraw a demo record.
- Management page to review records.
- Store data in browser localStorage.

## How to run
1. Extract the project folder and open it in VS Code.
2. Run `npm start` in the terminal, or open `index.html` in a browser.
3. Browse the sample fashion and select an option.
4. Enter your name and the requested details to save a demo record.
5. Open **My activity** to view or cancel the record.

## Technologies
HTML5, CSS3, JavaScript and browser localStorage.

## Academic demo note
This is a frontend lab demonstration with sample data. It does not connect to real external services, process actual payments, send SMS/email, or confirm real-world availability. Do not enter sensitive or real medical, financial, or voting information.
